# Troubleshooting

| Symptom                   | Likely cause          | Fix                                                        |
| ------------------------- | --------------------- | ---------------------------------------------------------- |
| No water flows            | Empty tank or airlock | Refill the tank and run the steam wand for 10 seconds.     |
| Coffee is sour            | Under-extraction      | Grind finer or increase the dose by 0.5 g.                 |
| Coffee is bitter          | Over-extraction       | Grind coarser or shorten the shot.                         |
| Descale light stays amber | Programme interrupted | Run the descale programme again from the start.            |
| Steam wand sputters       | Blocked steam tip     | Soak the tip in hot water and clear the holes with the pin. |
| Ring light blinks red     | Boiler overheated     | Switch off for 15 minutes, then refill the tank.           |

Still stuck? Contact support through the customer portal with your order
number and a short description of the fault.
